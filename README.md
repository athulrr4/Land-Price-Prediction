# Land Price Prediction Using Linear Regression

## Project Overview
This project focuses on predicting land prices based on land area using Machine Learning techniques. A Linear Regression model is used to understand the relationship between land area and its price.

## Objectives
- Analyze land price data.
- Perform data preprocessing.
- Visualize relationships in the dataset.
- Build a Linear Regression model.
- Predict land prices based on land area.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithm
- Linear Regression

1. Clone this repository.
2. Install the required libraries.
3. Open the Jupyter Notebook.
4. Run the notebook cells to train the model and predict land prices.
